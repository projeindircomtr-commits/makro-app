# Makro

Erisilebilirlik servisi ile calisan oyun makrosu. Root / ADB / PC gerekmez.

- Yuzen panel: sürükle, baslat/durdur, tus kaydet, HP/MP noktasi kaydet
- HP/MP bar rengini yari cozunurlukte, saniyede ~5 kare okur (kasmaz)
- Skill cooldown takibi, periyodik mob secme, normal saldiri
- Dokunuslar rastgele sapma, basma suresi ve bekleme ile
